# Automotive Aerodynamics & Airfoil Suite 🏎️💨

[![Domain](https://img.shields.io/badge/Domain-Automotive%20%26%20Aerospace-yellow.svg)](#)
[![Tech](https://img.shields.io/badge/Tech-Fluid%20Mechanics%20%7C%20NACA%20%7C%20Drag%20Power-brightgreen.svg)](#)

A simulation platform for automotive vehicle drag power calculation, NACA 4-digit airfoil geometry generation, and boundary layer streamline analysis:
$$F_d = \frac{1}{2}\rho v^2 C_d A$$

---

## 🌟 Key Features
- 🏎️ **Vehicle Aerodynamic Drag Force & Power Solver:** Computes kW / horsepower required to overcome aero resistance.
- 📐 **NACA 4-Digit Airfoil Geometry Engine:** Parametric airfoil generator for aerodynamic lift and drag polars.
- 🌊 **Streamline Flow Visualizer:** Real-time particle streamlines and boundary deflection.

---

## 🚀 Quick Start
```bash
git clone https://github.com/rushikeshgarad2024-dev/automotive-aerodynamics-suite.git
cd automotive-aerodynamics-suite
npx serve .
# Or run Python solver:
python aero_solver.py
```
